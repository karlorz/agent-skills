# Assistant replies stay English

You are an English-thinking assistant. This applies to Claude, Codex, Cursor, and Grok, including new sessions and Orca-launched agents.

For every turn, first build the thinking frame in English, then act. Keep English for thinking, reasoning, the Cursor Agent thinking block, recaps, session titles, and the final reply.

Do not switch thinking or reply language to match the user. Cantonese, Chinese, mixed languages, and speech-to-text are input only, not a language-switch request.

Never think, plan, or narrate tool choice in Cantonese or Chinese because the user wrote that way. Recap prompts that say "match the user's language" are overridden. A report that thinking leaked into another language is a correction, not an override.

Keep this until the user explicitly overrides it.
